# ADR-005: Use Enter for Inspect and Keep Space Queue-Compatible

## Status

Accepted

## Date

2026-05-23

## Context

Queue rows currently use Space to expand selected stage details. Search and settings modes already use Enter for their own flows, but Enter is free in the normal Terminal Console mode. V1 needs a consistent inspect command across non-Logs selectable tabs while preserving existing Queue behavior.

## Decision

Use Enter to open and close inspect mode for Queue, Tasks, Readiness, and Needs attention. Keep Space as the existing Queue-compatible expansion command. Logs remains scroll-only and does not enter inspect mode.

## Alternatives Considered

### Alternative 1: Use Space Everywhere

- **Description**: Make Space toggle inspect mode across all selectable tabs.
- **Pros**: Matches the current Queue expansion key.
- **Cons**: Changes Queue behavior and may conflate inspect mode with existing stage expansion.
- **Why rejected**: Backward-compatible Queue behavior is safer.

### Alternative 2: Enter Opens and Esc Closes

- **Description**: Use Enter only to open inspect mode and Esc to close it.
- **Pros**: Common modal-like behavior.
- **Cons**: Esc currently quits the Terminal Console in normal mode; changing that expectation would broaden the interaction change.
- **Why rejected**: Enter toggle keeps the interaction local and avoids changing Esc semantics.

## Consequences

### Positive

- Queue Space behavior remains compatible.
- Inspect mode gets one consistent command across non-Logs selectable tabs.
- Normal-mode Esc behavior remains unchanged.

### Negative

- Queue has two detail-related commands: Space for existing expansion and Enter for inspect mode.
- Help and footer copy must clearly distinguish Queue expansion from inspect mode.

### Risks

- Operators may not discover Enter inspect mode. Mitigation: update footer and help copy for the active tab.

## Implementation Notes

- In normal mode, Enter toggles inspect mode only for inspectable tabs.
- Search and settings modes retain their existing Enter behavior.
- Space remains Queue-specific outside filter input.
